QuickStudy: An Arabic-First Mobile Application for Reading and Studying Lecture Material

Requirements and Design Report · October 2026

Abstract. This report presents QuickStudy, an Android application that combines a PDF reader with study tools for Arabic-speaking university students. It defines the problem and the proposed solution, specifies the functional and non-functional requirements, compares the application with two existing products (Quizlet and Knowt), and presents low-fidelity wireframes of the main screens.

1. Introduction

1.1 Problem Statement

University students commonly study from PDF lecture slides and scanned textbooks. Reading, annotating and self-testing are usually done in separate applications. Existing study platforms are designed primarily for English and offer limited support for Arabic text, right-to-left (RTL) layouts and scanned Arabic documents.

1.2 Proposed Solution

QuickStudy integrates the full study cycle in one application: upload, read and annotate, organise by subject, and review. The reader supports notes, highlights and on-device optical character recognition (OCR) for scanned pages. Course files are organised into subjects and chapters, each linked to flashcards and quizzes. A later phase will generate study material automatically using artificial intelligence (AI) through a secure proxy server.

1.3 Scope and Target Users

The system targets Arabic-speaking students using Android phones. It operates offline and stores all files locally. Collaborative features and community-shared content are out of scope.

2. Functional Requirements

IDRequirement
FR-1The system shall allow the user to upload PDF and image files and store them locally.
FR-2The system shall display library books on shelves with cover previews and reading progress.
FR-3The system shall open a document at the last page read, in vertical or horizontal reading mode, with zoom.
FR-4The system shall allow the user to add typed notes, highlights and bookmarks to a document.
FR-5The system shall apply OCR to scanned pages so that their text can be selected.
FR-6The system shall provide reading settings: brightness, margins, paper colour and night mode.
FR-7The system shall allow the user to create, edit and delete subjects.
FR-8The system shall allow the user to add, rename, reorder and delete chapters within a subject.
FR-9The system shall keep study files separate from library files.
FR-10The system shall provide flashcard and quiz modes for each chapter.
FR-11The system shall support Arabic and English interfaces and light and dark themes.
FR-12The system shall generate summaries, flashcards and quizzes from a chapter using AI (future phase).

3. Non-Functional Requirements

IDCategoryRequirement
NFR-1PerformanceA page shall render within one second on a mid-range device, and heavy processing shall run in the background.
NFR-2AvailabilityAll features except AI generation shall work offline.
NFR-3Privacy and SecurityUser files shall remain on the device, and no secret API key shall be embedded in the application.
NFR-4LocalizationThe interface shall fully support Arabic, including RTL layout and Arabic plural forms.
NFR-5Usability and AccessibilityTouch targets shall be at least 44 px, and every screen shall define loading, empty and error states.
NFR-6ReliabilityDatabase upgrades shall preserve existing user data.
NFR-7MaintainabilityThe code shall follow the Model–View–ViewModel (MVVM) architecture with one-way data flow.

4. Comparative Analysis

Quizlet is a widely used flashcard platform with a large library of shared study sets and an AI tutor available to paid subscribers. It does not include a document reader, and its Arabic support is limited.

Knowt generates notes, flashcards and practice tests from uploaded files using AI. Files are processed in the cloud, and AI usage is limited on the free plan.

6. Conclusion

QuickStudy addresses the separation between reading and studying, and the limited Arabic support in current study applications. The core reading and organisation features are implemented. Future work will add AI-generated study material through a secure server, and an evaluation with student users.
