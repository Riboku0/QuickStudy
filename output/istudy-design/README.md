# Istudy design

12 English mobile screen concepts.

Open board-1.png, board-2.png, and board-3.png to review. Import istudy-all-screens.svg into Figma, or import individual files from screens/. SVG import may convert text to outlines depending on the importer; these are vector source files, not native Figma components.

The original Figma file was not edited because the connector reported the Starter plan tool-call limit.

Performance intent: reusable cards, flat vector icons, restrained effects, no continuous decorative animation, and isolated timer updates. Runtime performance has not been implemented or measured.

Example course/exam data is illustrative. The weekly progress chart totals 260 minutes over 8 sessions; subject progress measures course-topic completion, not just elapsed focus time.
